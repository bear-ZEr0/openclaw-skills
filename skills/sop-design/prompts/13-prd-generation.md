# 阶段13: PRD文档生成 (PRD Generation)

## 阶段目标
整合所有阶段的产出，生成完整的可执行PRD文档。

## AI角色
**文档工程师** - 组装、格式化、输出

## 输出格式

使用 templates/prd-template.md 模板，填入所有阶段的内容。

## 生成步骤

```
读取PRD模板
    ↓
填入各阶段内容
    ↓
格式化调整
    ↓
添加目录和链接
    ↓
输出完整PRD
```

## 填入内容清单

- [ ] 产品概述（来自阶段2）
- [ ] 用户画像（来自阶段2）
- [ ] 竞品分析（来自阶段3）
- [ ] 核心流程（来自阶段4）
- [ ] 功能规格（来自阶段5、6、10）
- [ ] UI设计（来自阶段7）
- [ ] 技术方案（来自阶段8、9）
- [ ] 风险评估（来自阶段11）
- [ ] 挑战记录（来自阶段12）
- [ ] 验收标准（来自阶段10）

## PRD输出后

```markdown
## PRD生成完成

文档已生成: [文件路径]

### 文档结构
- [ ] 产品概述
- [ ] 用户画像
- [ ] 功能规格（[N]个功能）
- [ ] 技术方案
- [ ] UI设计
- [ ] 风险评估
- [ ] 挑战记录
- [ ] 验收标准

### 关键数据
- 功能数量: [N]
- Must Have: [N]
- Should Have: [N]
- 测试用例: [N]

### 进入用户评审
现在进入打磨阶段，请审查PRD并提出修改意见。

> **PRD文件**: [路径]
> 
> 请审查以上内容，有任何修改意见请告诉我：
> - [ ] 整体结构OK
> - [ ] 功能描述需要调整
> - [ ] 技术方案需要讨论
> - [ ] UI设计需要修改
> - [ ] 其他：[请描述]
```

## 注意事项

1. **保持链接** - 确保各个章节之间的引用正确
2. **格式统一** - 使用一致的表格和列表格式
3. **版本信息** - 添加版本号和日期
4. **批准区域** - 预留用户签字确认的区域
