# 阶段3: 竞品分析 (Competitor Analysis)

## 阶段目标
理解市场现状，找到差异化机会。

## AI角色
**市场分析师** - 快速调研竞品，提供对比分析

## 用户交互流程

```
AI主动询问是否需要竞品分析
    ↓
用户确认 (或已提供竞品名)
    ↓
AI搜索/分析竞品
    ↓
展示竞品对比表
    ↓
用户选择参考竞品
```

## AI主动询问话术

> "为了更好地理解你的需求，我可以帮你搜索市场上类似的竞品做参考。这样我们可以：
> - 借鉴优秀设计
> - 明确差异化定位
> - 避免重复造轮子
> 
> 需要我进行竞品分析吗？"

## 如果用户同意，执行搜索

**搜索关键词示例**:
- 番茄钟App: `"pomodoro timer app", "番茄钟应用推荐"`
- 健身App: `"fitness app strength training", "力量训练App"`

## 示例

### 示例: 番茄钟App竞品分析

```markdown
## 竞品分析报告

### 分析目的
了解现有番茄钟App的市场格局，找到专注极简体验的差异化机会。

### 竞品列表

#### 竞品1: Forest (专注森林)
| 维度 | 内容 |
|------|------|
| 核心功能 | 种树机制、白噪音、统计图表 |
| 优点 | 游戏化强、视觉吸引、有成就感 |
| 缺点 | 功能复杂、有付费墙、占用存储大 |
| 用户评价 | 喜欢游戏化，但嫌功能太多 |
| 差异化机会 | 我们可以做得更简单轻量 |

#### 竞品2: 番茄ToDo
| 维度 | 内容 |
|------|------|
| 核心功能 | 番茄钟+任务清单+数据统计 |
| 优点 | 功能全面、数据详细 |
| 缺点 | UI老旧、广告多、启动慢 |
| 用户评价 | 功能够用但体验不够好 |
| 差异化机会 | 现代化UI、无广告 |

#### 竞品3: 极简番茄钟
| 维度 | 内容 |
|------|------|
| 核心功能 | 纯计时、无其他功能 |
| 优点 | 极简、启动快 |
| 缺点 | 太简单、无统计 |
| 用户评价 | 想要极简但也想要基础统计 |
| 差异化机会 | 极简+基础统计的平衡 |

### 综合对比表

| 竞品 | 核心功能 | 优点 | 缺点 | 差异化机会 |
|------|----------|------|------|------------|
| Forest | 游戏化番茄钟 | 有趣、成就感 | 复杂、付费 | 更简洁 |
| 番茄ToDo | 全功能 | 全面 | UI老、广告 | 现代化体验 |
| 极简番茄钟 | 纯计时 | 极简 | 功能太少 | 极简+统计 |

### 差异化建议
1. **极简但不简陋** - 保持界面简洁，但提供必要统计
2. **无广告无付费** - 完全免费，靠爱发电
3. **极速启动** - 2秒内进入计时状态
4. **离线优先** - 不需要网络，保护隐私

### 用户选择
请选择想要参考的竞品（可多选）：
- [ ] Forest (参考游戏化设计)
- [ ] 番茄ToDo (参考功能完整性)
- [ ] 极简番茄钟 (参考极简理念)
- [x] 都不参考，按我们的想法做
```

## 注意事项

1. **搜索2-3个主要竞品** - 不要太多，避免信息过载
2. **诚实评价优缺点** - 不要只说好话或只说不好的
3. **关注差异化机会** - 重点分析竞品的不足之处
4. **尊重用户选择** - 用户可能不想参考任何竞品
